# Changelog

## [1.2.0] - 2026-10-19

### Añadido

- Métricas de prácticas agrupadas por estado en el dashboard, con accesos directos a sus listados.
- Gestión manual del estado de las prácticas e historial de cambios.
- Revisión destacada de prácticas cuya fecha de término ya pasó.
- Respuesta del estudiante a una práctica observada para devolverla a revisión; la respuesta queda en el historial y genera notificaciones para gestores y administradores.
- Registro opcional de horas semanales y estimación de horas transcurridas.

### Cambiado

- La navegación desde solicitudes pendientes permite abrir las revisiones o una solicitud específica.
- Se agregan migraciones de base de datos para las horas semanales y las respuestas a observaciones.
